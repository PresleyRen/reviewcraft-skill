# 审稿、检测状态与投稿

## 先内容总审，再处理提交按钮

从标题、摘要、方法、主要综合、讨论和结论恢复中心论证，检查问题—证据—结论是否对应。重点看最近邻差异、检索/纳排、提取可靠性、异构比较、解释和工程用途。之后看语言、图表、引文、附件和政策。

采用作者能提出的最强回应挑战每项批评。保留真正问题：原文位置、短引文、观察证据、影响、严重程度、最小修复、关闭条件。区分已证实错误、缺少支持和待核问题。无须凑缺陷数量，不把综述没有训练新模型当作无效。

多个视角可由一名助手执行，但不能称独立专家评审。需要隔离或多人复核时按授权和实际可用能力执行，并记录真实来源。作者及模型审查一致不等于期刊已外审。

## 投稿前必过的核对

| 检查 | 保存什么依据 | 修改后如何处理 |
|---|---|---|
| 当前期刊规则 | 官网URL、日期、文章类型、条款与适用范围 | 换刊/规则改变时重核 |
| 覆盖与综合 | 搜索范围、停止理由、关键新增文献影响 | 扩展语料后复核中心判断 |
| 编码可靠性 | 实际字段核查、对象、发现、处理 | 新材料不继承旧抽样结果 |
| 最近邻与贡献 | 已有内容与新增综合的直接对照 | 主要论断改变时重审 |
| 全文审稿 | 确切版本哈希、覆盖、保留意见与修复 | 不能用旧稿审查批准新稿 |
| 引用与图表 | 身份/支持/编号/链接、数据/示意属性 | 正文与附件联动 |
| 中英文/格式 | 翻译语义、实际渲染、匿名与长度 | 同步受影响文件 |
| 作者与声明 | 真实名单、顺序、贡献、批准、经费、冲突 | 不从建议分工推断已完成 |
| 数据材料 | 可达性、版本、许可、审稿访问 | 上传/公开/授权分别记录 |
| 检测状态 | 实际报告或明确未执行/不要求的理由 | 报告绑定哈希和设置 |

全检通过后才冻结清单，然后按授权上传。最终核对门户文件身份和必需字段；若没能下载远端校验，明确本地哈希与门户文件名/上传完成是不同证据。

## AI与其他声明按实际政策核对

先取得当前目标指南和出版方规则；记录准确内容、版本/日期、用途、是否要求披露及位置。不同出版社、文章类型与图用途可能不同，不写一个适用于所有SCI期刊的固定声明。模型工具版本未知就不能编造。

清理重复、无关声明与满足必要披露可以同时完成：列出所在文件/原文/保留或删除原因，正文总声明、方法、图注、附件各按其适用要求处理。不要在所有图里随意添加生产过程口号，也不能用删内部记录使实际使用变成不存在。重要分歧给出官网具体条款和最小必要措辞，不反复争辩同一句话；继续不受影响的文件检查。

## 查重与AI检测分别记账

检测若为用户/期刊要求且未完成，不能称该项通过。若没有要求，可以明确未请求，不制造普遍的付费前置门槛。已有报告记录工具、日期、文件SHA、设置、分数、阈值来源及命中处理。报告支持该工具在该文件上的输出，不支持作者身份、研究原创性或录用保证。

本地检查器会验证报告文件和提交稿SHA的对应记录，但不判断上传到检测服务的实际字节，也不解析或鉴定报告真假；需要执行者核实。未检测不写0%。不能将语言润色当正式检测或保证“AI率<10%”。

## 作者、资料与操作授权

贡献按真实完成填写；通讯支持可按事实映射指导/资源/审阅，不能替他人分配已完成贡献。所有作者批准、无重复发表/同时审理、经费和冲突要有依据。

给期刊上传、给新检测平台上传、存储私有资料、公开资料及授予开放许可各有不同目的。已有有效授权不反复索取；新法律条款或范围扩大需按实际授权要求处理。Skill不自动同意条款、付款、公开资料、撤稿或重投。

## 提交后

状态分开：文件准备→已上传草稿→正式提交→技术检查→编辑处理→外审→决定→录用→发表。只能依据实际回执/通知推进。门户UUID不是必然的正式稿号；看到确认页也不能声称确认邮件已经送达。

保存时间原文及已知时区、期刊/类型、稿件哈希、提交材料、作者授权与回执。冻结提交源；用户要求复核就审查确切版本，不自动改提交文件。确有核心错误再说明影响与可行处理，不能因内部审查有改进建议就擅自撤稿。

返修按“意见→回答→实际修改/补证据→位置→验证状态”处理。先完成最小充分修复，不默认重启整个项目；未做的新检索或核验不能倒填为初投前完成。
