# 方法来源与适用范围

这是方法导读和溯源表，不是已完成某篇综述的检索证明。链接/元数据与相关部分核对日期：2026-10-29；动态出版政策在实际投稿前重核。没有转载完整论文、标准或其他技能代码。

| 来源 | 用于什么 | 读取和使用边界 |
|---|---|---|
| [ACM SIGSOFT Empirical Standards — Systematic Reviews](https://www2.sigsoft.org/EmpiricalStandards/docs/standards#systematic-reviews) | 问题、可检查的检索/提取/综合关系，以及证据和建议的区分 | 本轮核对相关标准部分；区分essential/desirable，不把建议统一变成期刊硬门槛 |
| [PRISMA-S，Rethlefsen等，2021](https://doi.org/10.1186/s13643-020-01542-z)；[原始报告全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC7839230/) | 检索来源、策略、日期、限制、去重与更新的报告 | 本轮读到官方PRISMA-Search说明与元数据；全文入口出现验证页面，未声称本轮全文精读。它是检索报告扩展，不是所有领域的完整研究设计规范 |
| [Kitchenham与Charters，2007，软件工程系统综述指南](https://www.elsevier.com/__data/promis_misc/525444systematicreviewsguide.pdf) | 协议、选择、提取和一致性检查的基本方法 | 复用先前读取的相关提取检查指导；本轮未重新阅读全文，不称已执行其完整流程 |
| [IST作者指南](https://www.sciencedirect.com/journal/information-and-software-technology/publish/guide-for-authors) | 目标期刊核验入口示例 | 本轮网页抓取403；此前项目核对不能替代未来投稿核验，不在仓库固化长度/费用等未重核值 |
| [Elsevier期刊生成式AI政策](https://www.elsevier.com/about/policies-and-standards/generative-ai-policies-for-journals) | 用途、图表和披露范围的动态核验入口 | 本轮核对官方搜索结果中的政策说明；使用时读取实际适用条款，不作为所有SCI统一政策 |

## 与已有个人技能的关系

- [ClearWeave](https://github.com/PresleyRen/clearweave-skill)：按含义编辑、处理模板化表达。本轮读取本地SKILL，未复制其脚本。
- [Paper Review Atlas](https://github.com/PresleyRen/paper-review-atlas)：有定位的审稿意见、最强作者回应、修复和关闭条件。本次此前已实际用于内部审查，仓库按经验编写阶段衔接。
- [Agent Research Atlas](https://github.com/PresleyRen/agent-research-atlas)：较广科研探索与证据地图。ReviewCraft聚焦综述从设计到交付，不替代实验研究工作流。
- [Scholar Route](https://github.com/PresleyRen/scholar-route)：领域、期刊与投稿路由，可选协作。
- [FigureFoundry](https://github.com/PresleyRen/figurefoundry-scientific-figures)：原生科研图与可编辑导出，可选协作。

以上链接的仓库存在性由本轮已连接GitHub账户仓库列表确认；未据此声称完整审计了各仓库代码、最新版本或兼容性。这些项目有各自许可。ReviewCraft的规则、模板和检查器为本次原创整合，不是上述项目或出版社的官方产品。
