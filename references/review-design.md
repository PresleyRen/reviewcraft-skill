# 先确定综述要增加什么

## 从读者决策进入，而不是先凑目录

用一句话说明：哪类读者在什么场景需要区分什么，现有综述为什么不足以直接支持这个判断。工程问题和论文问题可以互相验证：企业故障给出动机，原始论文给出已有方法、条件和证据。企业故事不是问题发生率，作者局限也不是未经查新的空白。

从少量最接近的综述、代表性原始研究及最新工作开始。为每篇保存版本、实际读到的章节、核心观察单位、分类维度、方法边界和明确局限。提案需要说明：旧综述已经解释什么，本稿增加何种跨研究比较，以及新增比较改变什么认识或选择。

可以形成贡献的是新综合、可检验的边界、冲突解释、统一比较条件、数据/协议资源或重要的经验发现。换个名称、更多分类框、热门模型清单和更长参考文献不自动构成贡献；有人研究过也不自动说明没有可写空间。

先用[方法与规范层级](method-authority.md)区分目标刊规定、报告指南、实施方法和写作经验。先查是否接受主动投稿或需要提案/邀稿，再投入整稿；通用指南与具体刊要求不一致时保留差异并核当日适用规则。

## 选适合的问题与综述类型

| 类型 | 核心任务 | 承诺和边界 |
|---|---|---|
| 叙述/批判性综述 | 用清楚的选材逻辑解释概念、争议、机制 | 不自称穷尽检索；来源仍须准确 |
| 系统映射 | 系统识别并组织某领域研究类型、证据与缺口 | 定义检索、纳排、单位、编码；分类之外还要综合 |
| 范围综述 | 澄清概念、范围及证据分布 | 按相应学科方法和报告指南执行 |
| 系统综述 | 回答具体问题并综合合适证据 | 搜索/选择/质量评价与目标匹配 |
| 元分析 | 对足够可比的估计进行定量综合 | 检查单位、独立性、异质性、偏倚与统计假设 |
| 有界证据地图 | 对明确检索集合及预算内追溯作可追溯分析 | 诚实报告未饱和和未知；不推断整个领域的缺失或比例 |

这些名称不能互相装饰使用。报告规范帮助写清发生了什么，不会自动使研究变成可靠系统综述。综述通常无需为了“有实验”训练模型；如果主张新评分器更准或工程收益已得到验证，就需要对应的实证支持。

## 同时核目标期刊与同类综述

使用期刊官方指南、费用页及明确年份的索引/分区来源，记录核验日期。核对：是否接收综述/是否仅邀稿、主题范围、文章类型、长度、图表与补充材料、数据要求、审稿方式、作者/利益冲突等声明。投稿费、审稿费、录用后费用和可选OA分别记；Subscription不等于所有项目在所有条件下零费用。分区标清JCR/中科院体系、学科与年份，新刊的索引状态不能猜。

官方公布的决定时间、接受后上线时间和作者经历是不同指标；没有官方录用率、配额或周期就记未知，不从博主推断“基本不拒”。费用可行不等于科学契合。

从目标期刊同类综述学习：问题如何引入、贡献怎样定位、方法透明度、表格如何综合、讨论如何回应结果、措辞及引用密度。优先少量结构相近且有全文的论文，按需要扩展。记录原文章节→其功能→适用于本稿的原则，不照抄句子或把其结论移入本稿。找不到同刊近邻时，用邻近领域加官方要求，并注明证据缺口。

## 收口与停止

在大量检索前形成一页开题：问题、读者、类型、最近邻、拟增加的综合、预计数据、检索/提取方案、预算、候选目标期刊或未定状态及停止条件。先小规模试提取，确认信息真实可取得；这不自动授权收费调用或新的人评。

停止/缩小条件可以是：最近邻已完整回答相同问题而本稿无新增综合；关键原文或数据不可获得；操作定义不清导致同一证据不能一致编码；新增材料持续推翻分类却无预算修正。记录具体原因、证据和重开条件。需要的是能改变决策的检查，不是证明自己最初的想法一定正确。
