# 检索、阅读与证据

## 可复查的搜索

策略调试和按方法实施的细节见[conduct-and-synthesis](conduct-and-synthesis.md)。来源按互补覆盖选择，不设通用数据库数量/论文数/语言比例或声望纳入门。主题词、字段、Boolean和过滤器按平台核对；作者/模型自检不宣称PRESS专家同行复核。已知关键论文可用于调试策略，不能据此估算总体召回率。

从研究问题提取概念块，同义词、旧术语和相邻术语都考虑。数据库采用各自字段/语法，不能把错误查询当零命中。保存检索平台、完整字符串、字段、日期、时间窗、返回数、导出数、分页、上限、失败、原响应位置和版本。计划使用某数据库不等于已经执行。记录查询修订及原因；回顾性整理的协议不得改称预注册。

种子包括最近邻综述、原始代表作和可能反驳论点的工作。前向/后向追溯保留种子、发生分支、候选身份及处理原因。补充固定ID检索只是身份/原文恢复，不等价于另一次关键词检索。

阅读预算停止时保留未完成候选，区分身份未绑定、全文未取得、已有全文未读和读后不符合。不能把前者称为“该能力不存在”。按中心结论分层处理剩余候选，不无限扩展无关祖先。

## 去重与纳排

数据库条目、预印本/正式版、报告族、研究、数据集、任务/会话、独立重复应分别标识。保留原ID和映射，不因重编序号改变其含义。相同数据复用影响独立性，不能把报告数当实验样本数。

预先定义纳排所需证据：研究对象、变化类型、接口、必要方法、版本和可读范围。先做小样本试编码，澄清边界，再扩大；修订规则时保留何时修订及受影响记录。混合研究只纳入对应子设置，背景论文与主分析分层。不要静默删掉失败/未知记录以让数字好看。

## 原文阅读卡

每条重要证据至少填写：

```text
报告ID/报告族 → 版本/DOI/来源URL → 实际读取范围
输入/任务 → 方法操作 → 比较与信息条件 → 评分端点/公式/分母
原文定位 → 作者结论 → 作者局限 → 我方解释/推断 → 未核项
```

只看摘要就记录摘要；读过方法也不能声称运行过实现。检索摘要、全文证据、代码审查和实际复现四种证据分开。原文没有报告与研究实际没有该能力不同。

缺陷可以推导新综合/方法，但要寻找最近邻替代方案、反例和不同术语下的相同机制。作者写“future work”不证明到今天仍无人解决。引用存在、元数据正确、该段支持论断是三层检查。

再分别检查版本、更正/撤稿与当前规范引用身份。数据库故障、online-first暂无卷页、文献未收录和真实身份冲突分开；不从索引未找到推出捏造，也不把DOI格式有效写成已验证。NLI或模型共识可用于筛查待核支持关系，不替代原文语义核验。

## 提取与复核

编码本明确字段、取值、边界例子和未知值。为每个关键字段保留原文定位与理由。抽样复核记录抽样框、单位、挑选方式、对象、字段分母、原值/复核值、发现、处理及影响；扩展新文献后明确哪些进入复核，不自动继承旧样本覆盖。

根据实际研究类型和资源选择复核方法。两个AI输出一致不是人工金标；同一助手模拟多个角色不等于独立专家；作者做过针对性检查，也不等于全部字段双人独立编码。没有实际独立标注就不编造一致性统计。

综合前检查主要结论是否因新增批次或合理纳排边界变化而改变。可以优先比较初始与扩展语料、已核字段与含未知字段的判断、不同报告族处理方式。结果不稳就说明具体受影响判断，缩小结论或针对性补读。

## 数据可用性

共享自己有权分享的搜索策略、筛选结果、证据编码与原生图源；第三方全文按许可处理，不默认再分发。原始网页响应、摘要和数据库导出也可能有条款。按需剔除私人资料、访问令牌、账户内容及无关项目材料。

仓库草稿、私有审稿访问、公开发布、获得PID和最终版本是不同状态。数据声明必须与实际可达内容及版本对应。允许私有审稿访问与否由目标规则决定；公开许可不能由脚本猜定。
